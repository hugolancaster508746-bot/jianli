气体水合物相平衡预测器

基于 Clausius–Clapeyron 关联式 + 公开实验数据标定，覆盖 CH₄ / CO₂ / H₂S / C₂H₆ / C₃H₈ / N₂ 单气体、混合气与热力学抑制剂（盐 / 甲醇 / 乙二醇）。给一组温度、压力、气体条件，即可直接预测水合物生成压力或判断是否生成。

纯水精度 RMS < 10% 混合气 · 抑制剂 教学 / 科研估算

预测计算

两种模式：① 输入温度 → 预测平衡压力；② 输入温度+压力 → 判断是否生成。

模型与标定参数

预测引擎：Clausius–Clapeyron 积分形式 ln P = a + b/T（P 单位 bar，T 单位 K）。各气体用公开实验数据最小二乘标定。
ln(P[bar]) = a + b / T   |   抑制剂：等效为纯水在 T + ΔT 处的平衡压力   |   混合气：1/P = Σ(yᵢ/Pᵢ)
气体结构ab可靠温区标定 RMS
标定数据来源：CH₄/CO₂（Frontiers 2021、PMC 实验表）、H₂S（ACS J. Chem. Eng. Data）、C₂H₆（100 nm 孔≈本体）、C₃H₈（Lw–H–V 三相线）、N₂（van Cleeff & Diepen 等实验值）。CO₂ 超过上四相点 Q2（10 °C, 45 bar）进入液态 CO₂ 共存区，工具不覆盖。

文献学习综述（网络检索整理）

1 · 相平衡模型的两大路线

统计热力学路线（vdW–P / Kihara）：van der Waals & Platteeuw (1959) 把水合物看作"固体溶液"，用 Kihara 球对称势能算 Langmuir 常数、配 Peng–Robinson 等状态方程算气相逸度；Klauda–Sandler、Chen–Guo 在此基础上发展出力更稳的"逸度法"。这是 CSMGem、Multiflash 等工业软件的内核。

经验关联式路线（本工具采用）：对单一纯气体，相平衡条件直接积分得到 Clausius–Clapeyron 形式 ln P = a + b/T，用实验点标定 a、b。优点：透明、可解释、外推稳，无需状态方程迭代——非常适合教学与快速估算。

2 · CO₂ 水合物的两个四相点（关键！）

CO₂ 与甲烷不同，存在液态 CO₂ 共存段，导致相图在 Q2 = 283 K / 45 bar 出现斜率突变（上四相点：水合物+水+液态 CO₂+气相）；下方还有 Q1 = 271.6 K / 10.4 bar（冰+水+水合物+气相）。这正是早先用单一直线外推会差 3 倍的根源。

3 · 热力学抑制剂（让水合物更难生成）

本质是降低水活度 a_w，把相平衡线向右（高压）推。本工具统一用"生成温度下降量 ΔT"处理：NaCl 用冰点下降近似 ΔT = 1.86 × 摩尔浓度；甲醇/MEG 用 2024 年 ChemEngineering 二次式（ΔT = 0.3938x + 0.006166x² 等）。这正是输气管道防冰堵的原理。

4 · 机器学习的最新进展（2024–2025）

2025 年 ACS《Energy & Fuels》综述指出，ANN / SVR / RF / DNN 已成为主流，随机森林 R² 可达 0.96；但缺乏不确定性量化、外推能力差。这反衬出"物理约束 + 实验标定"的关联式在可靠性和可解释性上的优势。物理引导神经网络（PGNN）是二者融合的前沿方向。

5 · 权威实验数据库

NIST 气体水合物标准参考数据库 SRD #156（约 12000 个实验点、150 种化合物）免费开放，是标定模型的首选数据源。

术语词典（给非技术读者）

水合物 Hydrate
气体分子被水分子"笼子"关住形成的冰状晶体，如可燃冰（甲烷水合物）。
客体 / 主体 guest / host
客体=被关的气体分子；主体=搭笼子的水分子骨架。
结构 I / II / H (sI/sII/sH)
水分子笼的不同堆积方式；小客体（CH₄、CO₂）多成 sI，稍大（N₂、丙烷）多成 sII。
相平衡 / 相图
水合物相与气/液/冰相"和平共处"的温度-压力边界；线左生成、线右分解。
四相点 Quadruple point
四个相共存的唯一点（自由度=0），如 CO₂ 的 Q1、Q2。
Clausius–Clapeyron
描述相变时压力随温度变化的公式；积分即得本工具的 ln P = a + b/T。
抑制剂 Inhibitor
加盐/醇使水合物更难生成的物质，用于管道防堵（降生成温度）。
Langmuir 常数
统计热力学里描述气体分子"进笼概率"的参数，由 Kihara 势能积分得到。
水活度 a_w
水中"有效水分"的度量；抑制剂降低 a_w，等于抬高了生成门槛。
