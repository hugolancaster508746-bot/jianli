# 气体水合物相平衡预测器

基于 **Clausius–Clapeyron 关联式 + 公开实验数据标定** 的单文件网页预测器，用于估算气体水合物的生成平衡压力。

## 功能
- **预测平衡压力**：输入温度 → 输出在该温度下生成水合物所需的平衡压力（bar / MPa）
- **判断是否生成**：输入温度 + 压力 → 判断是否生成水合物
- **多气体**：CH₄ / CO₂ / H₂S / C₂H₆ / C₃H₈ / N₂
- **混合气**：Lipenkov–Istomin 组合规则 `1/P = Σ(yᵢ / Pᵢ)`
- **抑制剂**：NaCl（盐度）/ 甲醇 MeOH / 乙二醇 MEG，统一用生成温度下降量 ΔT 修正
- **相图**：对数压力轴温度–压力相图，含 CO₂ 上/下四相点 Q2 / Q1 标注

## 模型
预测引擎为相平衡条件的积分形式：

```
ln P[bar] = a + b / T      （P: bar, T: K）
```

各气体用公开实验数据最小二乘标定。抑制剂将问题等效为纯水在 `T + ΔT` 处的平衡压力；混合气用组合规则求解。

## 标定精度（与公开实验数据留一交叉验证）
| 气体 | 标定 RMS | 独立文献验证误差 |
|---|---|---|
| CH₄ | — | ±5% 内 |
| CO₂ | — | ≈2.8%（受上四相点 Q2 限制，仅 0~10°C）|
| H₂S | 1.9% | 外推 ≈ −8.6% |
| C₂H₆ | 4.7% | 混合气交叉验证 ≈3.2% |
| C₃H₈ | 0.9% | — |
| N₂ | — | −6.3%（冰相区）|

## 已知局限
- CO₂ 超过上四相点 Q2（10°C, 45 bar）进入液态 CO₂ 共存区，工具不覆盖；
- 高浓度 NaCl（>10 wt%）用冰点下降近似会偏小 10–15%；
- 跨结构混合气（如 CH₄ + C₃H₈）组合规则系统性偏高约 25–40%。
